# DayGraph 다운로드

DayGraph의 Windows 설치 파일과 자동 업데이트 정보를 배포하는 저장소입니다.

[최신 설치 파일 다운로드](https://github.com/mandelina/DayGraph-releases/releases/latest)

- Windows x64 설치형의 `DayGraph-<버전>-Windows-x64-Setup.exe`를 사용하세요.
- GitHub 로그인이나 토큰 설정 없이 다운로드하고 업데이트할 수 있습니다.
- 앱 설정에서 업데이트를 확인하고, 다운로드가 끝나면 재시작하여 설치합니다.
- 0.1.1 또는 0.1.2 사용자는 0.1.3 이상의 설치본으로 한 번 교체해야 합니다.
- 현재 설치본은 코드 서명이 없어 Windows 보안 경고가 표시될 수 있습니다.

활동 기록은 PC에 저장됩니다. 이 저장소에는 설치 파일과 업데이트 메타데이터만 배포하며 개발 소스와 Git 이력은 포함하지 않습니다.
