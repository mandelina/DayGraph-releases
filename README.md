# DayGraph 다운로드

하루의 작업 흐름을 한눈에 돌아보세요. DayGraph는 앱 사용 시간과 활동 기록을 내 컴퓨터에 저장하는 생산성 앱입니다.

[최신 버전 다운로드](https://github.com/mandelina/DayGraph-releases/releases/latest)

## 내 컴퓨터에 맞는 파일 고르기

| 운영체제 | 다운로드할 파일 |
| --- | --- |
| Windows x64 | `DayGraph-<버전>-Windows-x64-Setup.exe` |
| Apple Silicon Mac (M 시리즈) | `DayGraph-<버전>-macOS-arm64-Test.dmg` |
| Intel Mac | `DayGraph-<버전>-macOS-x64-Test.dmg` |

GitHub 로그인이나 토큰 설정 없이 다운로드할 수 있습니다. `.sha256`, `.blockmap`, `latest.yml`은 검증·업데이트용 파일이므로 일반 설치에는 필요하지 않습니다.

## Windows 설치와 업데이트

EXE를 실행해 설치해주세요. 설치형 앱은 새 버전을 자동으로 확인하고 다운로드합니다. 앱 설정에서도 업데이트를 확인할 수 있으며, 다운로드가 끝나면 재시작하여 설치합니다.

0.1.1 또는 0.1.2 사용자는 0.1.3 이상의 설치본으로 한 번 교체해주세요. 현재 설치본에는 코드 서명이 없어 Windows 보안 경고가 표시될 수 있습니다.

## Mac 테스트 버전

내 Mac에 맞는 DMG를 열고 DayGraph를 응용 프로그램 폴더로 옮겨주세요.

현재 Mac 버전은 Apple 개발자 서명·공증을 받지 않은 테스트용입니다. 임시 서명(ad-hoc)만 적용되어 실행 시 macOS 보안 경고나 차단이 발생할 수 있습니다. 실제 Mac에서의 실행과 권한 설정은 추가 확인이 필요합니다.

Mac 자동 업데이트는 아직 지원하지 않습니다. 새 버전이 나오면 이 페이지에서 DMG를 다시 다운로드해 설치해주세요.

## 내 기록은 내 컴퓨터에

활동 기록은 내 컴퓨터에 저장됩니다. 이 저장소에는 설치 파일과 업데이트 정보만 공개하며, 앱 소스와 개발 이력은 별도의 비공개 저장소에서 관리합니다.
